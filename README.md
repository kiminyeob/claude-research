# claude-research

TX360 AI 에이전트 도입을 위한 조사·검토 기록을 모아 두는 저장소.

## 작업 규칙

`main`에 직접 커밋·푸시한다. 상세 지침은 [CLAUDE.md](CLAUDE.md) 참고.

## 문서 위치

- `research/` — 조사 결과와 논의 자료. 파일명은 `YYYY-MM-DD-주제.md`

## 근거 표기 규칙

모든 사실 주장에는 출처 링크와 함께 검증 등급을 붙인다.

| 등급 | 의미 |
|---|---|
| `[검증됨]` | 1차 출처(공식 문서·스펙 원문)를 직접 열어 확인함 |
| `[부분 검증]` | 일부만 1차 출처로 확인되고 나머지는 미확인 |
| `[미검증]` | 원문에 접근하지 못해 검색 발췌로만 확인함. 사람이 직접 열어 확인해야 함 |

근거 없는 단정은 쓰지 않는다. 확인하지 못한 것은 "확인하지 못했다"고 적는다.
